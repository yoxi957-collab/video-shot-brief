# Video shot brief builder

A small offline tool for turning a video idea into a reusable shot brief. It combines a subject, setting, one action, camera instruction, and lighting notes, then exports the brief and your review notes as JSON.

## Use

Open `index.html` in a browser. No build step, account, external dependency, or API key is needed. Press **Build brief** to assemble your prompt and save the draft locally. **Download JSON** exports the current fields; **Clear saved draft** removes the stored draft.

Inputs stay in your browser's local storage. Storage can be unavailable in private browsing or restricted file contexts; the form and JSON download still work.

You can use the prompt in [Seedance's video workspace](https://seedance2-5.co/generator) or [WAN's workspace](https://wan30.io). Check the settings and credit estimate in the selected workspace. This tool does not call a model, calculate pricing, or guarantee a generated result.

## Example

Subject: a glass perfume bottle. Setting: a pale stone counter by a window. Action: the bottle stays still. Camera: a slow move from left to right. Light: soft morning light, simple background.

Change one decision between versions and watch the complete output before recording your review notes.
